One list for everything that expires

Certificates lapse, domains drop, licenses run out and contracts renew themselves. Most teams find out too late. Expiry Tracker turns each date into a Jira issue while there is still time.

A Jira issue, not another inbox

Reminders arrive where your team already works: one issue per reminder in the project you choose, assigned to the item's owner. Never duplicates.

Dates you do not have to type

Domain expiry dates come from the registry. Certificate dates come from a tiny open-source agent on your network, so internal hosts work too.

Built to be trusted

If a lookup fails you see why next to the item. If an issue cannot be created it is retried the next day. If the agent goes quiet you get an issue about that as well.

How it works

Set it up in a few minutes. After that it runs once a day on its own.

1

Add what you want to track

A name, an owner, and a host, a domain or a date. Optionally vendor, cost and a note.

2

Choose where issues go

A Jira administrator picks the project, the issue type and how many days ahead to remind.

3

Renew in time

The owner gets an issue before the date. When the item is renewed, the reminders start over for the new date.

Your data stays in Atlassian

Expiry Tracker runs on Atlassian Forge and stores its data in Forge storage for your site. We run no servers that receive it, and we use no analytics or tracking. The only thing that leaves Atlassian is a domain name, sent to that domain's registry to read its expiry date. Privacy policy · Security
